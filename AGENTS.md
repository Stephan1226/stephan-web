## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Data access

All note data must go through `notesRepository` (`src/lib/notes/index.ts`), never
`getCollection` directly in pages or components. The repository pattern exists so the
Markdown content collection can later be swapped for a database (e.g. Cloudflare D1)
by replacing the implementation in `src/lib/notes/index.ts` only.
